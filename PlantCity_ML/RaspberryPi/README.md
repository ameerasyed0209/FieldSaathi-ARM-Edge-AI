# Raspberry Pi Edge AI Runtime

This module is designed to run the local language model on Raspberry Pi 4B (4 GB RAM).

## Hardware
- Raspberry Pi 4B
- ARM Cortex-A72 CPU
- 4 GB RAM
- Raspberry Pi OS 64-bit

## Software
- ExecuTorch
- XNNPACK backend
- Llama 3.2 1B Instruct (GPTQ quantized model)
