# AI Models

This directory contains information about the machine learning models used in FieldSaathi.

## Plant Classification
- MobileNetV2-based PlantCity model
- 52 classification classes
- TensorFlow Lite format
- Input resolution: 224 × 224

## Language Model
- Llama 3.2 1B Instruct
- GPTQ quantized ExecuTorch model
- Intended for local inference on Raspberry Pi 4B

## Model Files
Large model files are not included in this repository. Their download sources and deployment instructions will be documented separately.
